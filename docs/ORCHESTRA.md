# Оркестр: диалог, штаб, подключение, крошки

Числа считает ядро, агент их объясняет. Оркестр — это всё, что вокруг
модели в АГЕНТЕ: с кем говоришь (диалог), кого посылаешь (штаб), через
что подключён (подключение) и кто считает без модели вообще (крошки).

Готовые вопросы — в [`AGENT_PROMPTS.md`](AGENT_PROMPTS.md), там же честная
оговорка про точность.

## Быстрый старт

1. Вставь API-ключ прямо в строку диалога и нажми Enter. Ключ живёт только
   до закрытия терминала, никуда не сохраняется. Без ключа тоже можно:
   агент ответит по уже посчитанным числам.
2. Спроси обычным языком. Что агент сделал перед ответом (загрузил файл,
   переключил участок, посчитал расписание) — в ТРАССЕ справа; любой ответ
   перепроверяется командой (`/doctor`, `/compare`, `/bounds`).
3. Нужно несколько мнений сразу — отправь миссию из ШТАБА: выбери
   подключение и участок работы, впиши задачу, Enter.

## Четыре части

### Диалог

Один разговор на сессию (`session.dialog`): вкладка в КОДЕ, колонка и экран
АГЕНТА показывают одно и то же. История заданных вопросов — в развороте
ДИАЛОГА, клик повторяет вопрос. `/clear` чистит ленту, не историю.

### Штаб (`vliw/agent/hq.py`)

Фоновые агенты на проверенных подключениях: у каждого своё подключение
(снимок backend из каталога), свой участок работы и свой скрипт-дописка
к промпту. Агент только читает состояние — сессию не переключает, файлы
не грузит, ничего не пишет.

Участки: потери, сравнение, предел, раскладка, свой вопрос. Мини-блока
хватает, чтобы отправить задачу; разворот даёт подключения, скрипт
и список миссий (ещё раз / убрать / убрать выполненные).

### Подключение (каталог моделей, `vliw/agent/models.py`)

Правило: без ключа списка нет. Ключ → «подключить» → живой каталог
от сервера, клик применяет модель на сессию. Поиск — только фильтр
списка, Enter берёт первую строку. Где каталога нет (Yandex и подобные) —
ручной ввод ID с платной проверкой через API. Локальный сервер
(Ollama / LM Studio / llama.cpp) — пресет или свой URL, модели
скачиваются и запускаются вручную, не здесь.

Всё только в память процесса: смена ключа даёт свежий список, перезапуск
всё забывает — как и сами ключи.

### Крошки (`vliw/tiny/`)

Обученный планировщик без LLM: крошка-1 (порядок из скоров MLP),
крошка-2 (+ запреты «не раньше»), крошка-3 (веер из 32 вариантов, точный
выбор по makespan). Хуже baseline не бывает по построению. Подробно —
[`TINY.md`](TINY.md).

Синергия с оркестром — в одну сторону: `tiny_facts()` в
`agent/context.py` кладёт число крошек в контекст, агент его объясняет.
Обратное (модель подсказывает планировщику) — выдумка вместо поиска,
запрещено правилом честности из [`CAB.md`](CAB.md). Открытые шаги
(область «крошки» в штабе, строка крошек в мини, статус весов) —
в [`REDESIGN.md`](REDESIGN.md#открытый-вопрос-синергия-штаба-с-крошками).

## Правила честности

1. Модель не видит исходник, не видит решётку и не умеет считать.
   Всё, что она может, — пересказать факты из «ЧТО ВИДИТ АГЕНТ».
   Числа из ответа, которых нет в этом списке, выдуманы.
2. Ничьи в портфеле отдаются baseline, а не модели: не приписывать
   алгоритму чужое.
3. Трасса — не украшение: каждый шаг агента повторяется руками,
   командами из ответа.

## Где что лежит

| файл | роль |
|---|---|
| `vliw/agent/agent.py` | диалог: поток вопросов, действия до ответа |
| `vliw/agent/context.py` | факты в модель (машина, расписания, крошки, диагноз) |
| `vliw/agent/llm.py` | провайдеры, ключи, активная модель — всё на сессию |
| `vliw/agent/models.py` | живой каталог: `live / locked / unsupported / text` |
| `vliw/agent/hq.py` | штаб: области, сборка промпта миссии, вызов backend |
| `vliw/agent/local.py` | локальный подъём обученной модели (см. [`LEARNED.md`](LEARNED.md)) |
| `vliw/tui/screens/agent_screen.py` | экран: диалог, штаб, подключение, факты, трасса |
| `tests/test_tui_smoke.py` (`TestHeadquartersPanel`, `TestModelCatalogPanel`) | интерфейс headless |
| `tests/test_hq.py`, `tests/test_agent_backends.py` | штаб и провайдеры без сети |

## Проверки

```bash
python -m unittest tests.test_tui_smoke.TestHeadquartersPanel \
    tests.test_tui_smoke.TestModelCatalogPanel tests.test_hq \
    tests.test_agent_backends
```

Ни один тест не пишет на диск и не ходит в сеть (каталог — мок).
Полный гейт — `python -m unittest discover -s tests` (см. CI).
