# Origin of the NNL Core

The files below were copied byte-for-byte without modification from [smworklair/NNL](https://github.com/smworklair/NNL) at commit `6b0c9e0ffebdc5383ea226fa30f2cb23b67b6a24` (2026-10-20):

| here | in NNL |
|---|---|
| `NNL/матплата.py`, `NNL/процессор.py`, `NNL/ядро.py`, `NNL/решатель.py`, `NNL/линтер.py` | `NNL/…` |
| `архитектуры/мешок_шина.py` | `система/архитектуры/мешок_шина.py` |
| `обучение/сеть.py` | `система/обучение/сеть.py` |
| `СТАНДАРТ_БЛОКА.md` | `NNL/СТАНДАРТ_БЛОКА.md` |

Only empty `__init__.py` files (`nnl_vliw/`, `NNL/`, `обучение/`) were added so the package is importable.
Everything else in `nnl_vliw/` (graph token language, two cores, data preparation, training, evaluation, tests) was written for this project and leaves the NNL core untouched. To update the vendored copy, pull the same paths from NNL at the desired commit and run `python3 -m unittest tests.test_nnl_vliw`.
