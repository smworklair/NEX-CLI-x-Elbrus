# Промпт для новой сессии: визуальный дизайн CLI (продолжение)

Скопируй всё, что ниже разделителя, в новый чат. Это не первая сессия —
внутри уже сделано много, и промпт написан так, чтобы не переоткрывать то,
что уже решено, и не наступать на те же грабли.

---

Проект: `~/vliw-ai-scheduler-demo`, публичное имя **NEX CLI**. Инструмент
диагностики планирования инструкций для процессора Эльбрус (e2k). Питон,
интерфейс на Textual. Полноэкранный режим: `python3 -m vliw` без аргументов,
ветка `learned-in-ui`.

## Твоя задача одной фразой

**Каждая панель при развороте на весь экран — это мега-функциональный
инструмент под СВОЮ конкретную задачу, а не увеличенная копия того же
текста.** Часть панелей это уже получила (список ниже, не переделывай),
часть — ещё нет. Твоя работа — довести оставшиеся до того же калибра и
искать, где ещё осталось «большое окно с выводом» вместо инструмента.

Что это НЕ: не переписывание архитектуры, не дизайн-документы вместо
работы, не косметика поверх той же функциональности.

## Как понять калибр — три примера уже сделанного, которые надо повторить

Это не «для вдохновения», это буквально планка. Если твоё решение для
следующей панели слабее любого из трёх — переделывай, не показывай как
готовое.

1. **Настоящая аналитика, не текстовый вывод.** МАШИНА и УЧАСТОК в РАЗБОРЕ
   (`vliw/tui/screens/lab_screen.py`, методы `_draw_machine_matrix` и
   `_draw_scen_catalog`) — это `DataTable`, а не `Static` с текстом. Клик по
   заголовку столбца сортирует (повторный клик — переворачивает, стрелка
   ▾/▴ в заголовке показывает текущую сортировку), живой текстовый фильтр
   над таблицей прячет несовпавшие строки на лету, клик по строке делает
   РЕАЛЬНОЕ действие (переход к операции в решётке / переключение участка
   через `/run`). Раньше это был вычисленный, но НЕПОДВИЖНЫЙ текст — ровно
   то, что и в свёрнутом виде можно пересказать столбиком. Разница между
   «показал числа» и «дал таблицей манипулировать» — вот она.
2. **Настоящий терминал, не список для чтения.** ВЫВОД КОМАНД развёрнутый
   (`ConsoleJournal` в `vliw/tui/widgets.py`) — своя строка ввода прямо в
   панели («nex ▸ …»), команда выполняется, не выходя из разворота, и
   журнал сам прыгает на новый запуск. Раньше можно было прочитать прошлые
   запуски, но не работать оттуда.
3. **Настоящий агентный доступ, не справочный чат.** Всплывающая строка
   любой панели (`PanelPrompt` в `vliw/tui/widgets.py`, подключена в
   `ModeScreen._panel_prompt_worker` в `screens/base.py`) отвечает ТЕМ ЖЕ
   `Agent.ask_stream`, что ведёт экран АГЕНТ: «переключись на mulclash и
   сравни» из попапа МАШИНЫ в РАЗБОРЕ реально переключает сценарий и
   пересчитывает — это не облегчённая копия, которая только пересказывает
   заранее собранные факты. Действия агента показаны отдельной строкой
   («⚙ …», свой цвет) НАД ответом, в порядке событий, а не вперемешку.
   Уточнение с прошлой сессии: НЕ строй поверх этого многошаговый
   автономный режим («разбери всё сам, я не буду переспрашивать каждый
   шаг») — это НЕ было запрошено, конкретно это отклонили. Однократное
   действие + один ответ на вопрос — правильный уровень.

Общий принцип разворота (см. `docs/` нет отдельного файла, но код это уже
отражает): открыл ДИАГНОЗ — там ищут решение, откуда данные и как их менять,
а не тот же текст крупнее. У каждой панели — свой набор функций под ЕЁ
задачу, не универсальный виджет-помощник на все панели.

## Что уже сделано, не переделывай

Смотри `git log --oneline` от `7d3f8ea` до `HEAD` — там всё по коммитам с
подробным «почему». Коротко:

- Развороты своим инструментом у: РЕШЁТКИ и ДИАГНОЗА (список находок,
  фильтр по серьёзности, переход находка↔клетка в обе стороны), ЧИСЕЛ
  (вывод предела: диаграмма критического пути по тактам + разбор ресурсной
  границы), МАШИНЫ (интерактивная матрица, см. выше), ПОЧЕМУ ЗДЕСЬ (окно
  операции + конус зависимостей по графу, кликабельные ссылки на соседей),
  ВЫВОДА КОМАНД (журнал-терминал, см. выше), УЧАСТКА (интерактивный
  каталог, см. выше) — все в РАЗБОРЕ; ЧТО ВИДИТ АГЕНТ (контекст дословно —
  ровно те строки, что уходят в модель, с числом токенов) и ТРАССА (шаги
  агента по одному) в АГЕНТЕ; ЛЕНТА (лист вычислений: что каждая строка
  дала и сколько операций добавила в граф), ИМЕНА (откуда взялось
  значение), ПАМЯТЬ (карта всех 64 ячеек, клик подставляет в ввод),
  ПРОГРАММА (граф по ярусам), ЧЕМ СЧИТАТЬ (каталог ядер) в ЯДРЕ.
- Всплывающая строка вопроса (`PanelPrompt`) — у ЛЮБОЙ панели с фактами или
  готовыми вопросами, снизу, не отбирает ширину, закрывается по Esc (клавиша
  напечатана текстом «✕ Esc», не только tooltip), `/clear` стирает только
  разговор, факты и чипы остаются.
- Esc из пустой строки ввода в ЯДРЕ и АГЕНТЕ уводит на выбор режима (в
  РАЗБОРЕ Esc занят переключением решётка⇄ввод, это НЕ трогать).
- Цветокоррекция и иерархия панелей из середины сессии были ОТКАЧЕНЫ по
  прямой просьбе — не восстанавливай коммит `a855965`, он специально

## Известная ловушка Textual — уже дважды кусала

Textual вызывает обработчик `on_<имя_события>` у КАЖДОГО класса в цепочке
наследования, если он там определён (`MessagePump._get_dispatch_methods`),
а НЕ только у самого специфичного, как обычный Python. Дважды ловилось на
этом:
- `on_panel_expanded`/`on_panel_collapsed`, переопределённые в экране И в
  базовом `ModeScreen`, вызывались ОБА — решение: не звать `super()` вручную,
  Textual уже позовёт сам.
- `on_prompt_bar_escaped` в РАЗБОРЕ и в базовом классе делали РАЗНОЕ и
  взаимоисключающее — решение: `event.prevent_default()` (не только
  `.stop()`) в переопределении, это буквально то, что Textual для этого
  документирует.

Если переопределяешь обработчик сообщения, который уже есть в
`ModeScreen` (`screens/base.py`), проверь это заранее, а не когда упадёт.

## Важное ограничение — не изменилось

Языковая модель локальная (Qwen2.5-3B в 4 битах, llama.cpp, без GPU),
ответ 12–20 секунд, врёт при просьбе рассуждать. Ничто в интерфейсе не
ждёт модель, всё, что она сказала, визуально отделено от посчитанного
(своя строка/цвет). Это уже так устроено везде — не сломай при добавлении
нового.

## Как со мной работать

Смотрю на экран, вижу косяки сам. Хочу того же от тебя: находи проблемы,
предлагай решения, делай. Нужны нестандартные решения под каждую панель
отдельно, не один универсальный виджет на всё.

Чего не делать:
- не задавай уточняющих вопросов после каждого шага — я отвечаю с телефона;
- не лепи один виджет на все экраны — у каждого своя логика;
- не пиши мне документы и планы вместо работы;
- не спрашивай «делать это или то» — делай, потом показывай.

## Как увидеть результат

Полноэкранный режим требует настоящего tty, из скрипта не поднимается.
Снимай headless через тестовый харнесс Textual:

```python
import asyncio, io, sys
from contextlib import redirect_stdout
sys.path.insert(0, "/home/shokha/vliw-ai-scheduler-demo")
from vliw import cli

async def run():
    from vliw.tui.app import NexApp
    args = cli._build_parser().parse_args([])
    session = cli.Session(args=args)
    mode = "lab"                      # или "work" (ЯДРО), или "mind" (АГЕНТ)
    cli._apply_mode(session, mode)
    app = NexApp(session, lambda l: cli.handle_input(session, l),
                 cli.COMMANDS, start_mode=mode)
    with redirect_stdout(io.StringIO()):
        async with app.run_test(size=(150, 46)) as pilot:
            await pilot.pause(); await pilot.pause()
            app.save_screenshot("/tmp/shot.svg")

asyncio.run(run())
```

Чтобы попасть в развёрнутый режим панели — в скрипте, не только руками:

```python
from vliw.tui.widgets import Panel
panel = app.screen.query_one("#p-machine", Panel)   # id панели из compose_body
app.screen.maximize(panel, container=False)
panel.post_message(Panel.Expanded(panel))
await pilot.pause(); await pilot.pause()
```

SVG в PNG:

```bash
.venv/bin/python -c "import cairosvg; cairosvg.svg2png(url='/tmp/shot.svg', write_to='/tmp/shot.png', scale=1.4)"
```

Тесты: `.venv/bin/python -m unittest discover -s tests -t . -q` (сейчас 179,
должны остаться зелёными). Полноэкранный режим закрыт смоук-тестами в
`tests/test_tui_smoke.py` — там же примеры, как программно кликать по
заголовкам DataTable, печатать в фильтр и т.п., если нужен образец.
