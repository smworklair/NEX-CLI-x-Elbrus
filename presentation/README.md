# Презентация NEX CLI × Эльбрус

- `NEX_deck.pdf` — все 28 слайдов одним файлом.
- `00_overview.png` — обзор всех слайдов на одной картинке.
- `slides/` — те же 28 слайдов отдельными PNG (2000×1500).
- `screens_clean/` — 19 настоящих скриншотов интерфейса, 1920×1080, без пометок.
- `screens_annotated/` — 18 тех же кадров с подсветкой, номерами и стрелками, 1920×1080.

Скриншоты сняты в headless-режиме на реальных примерах из `examples/`. Такты в презентации модельные, не замеры на железе.
