# Форма графа: правило, не сеть

Ветка `nnl-rewrite` от `nnl-in-cli` (`8960dfe`). Числа — из `results/сводка.json`, прогон `python -m nnl_rewrite.прогон`. На `eval_*` не учились. Ядро NNL не добавлялось.

Движок пробует три законных приёма и оставляет граф, только если жадный стал короче и `validate()` пуст. Плавающая точка выключена, пока в вызов явно не передан `fp=True`.

## А. Учебные сценарии

Жадный, модель `e2k-v6-measured`. `seqreduce` 14 тактов, после «дерево ADD» 11 — столько же, сколько готовый `treereduce`. Тест `tests/test_rewrite.py` это проверяет. `divpressure`, `slotclash`, `unroll4`, `ifconv` движок не трогает: делить на степень двойки там не из чего, цепочки адресов нет.

## Б. Настоящие блоки `real_candidates_100_400/asm`

238 блоков с операциями, из них 196 линейных. Жадный: 2075 тактов на линейных, 3047 со всеми (42 блока `loop_mode` модель итерацией не считает).

| Приём | Блоков короче | Такты |
|---|---:|---:|
| дерево ADD | 0 | 0 |
| цепочка адресов | 1 (`emb_iir.s` блок 11, 17→16, не цикл) | 1 |
| сдвиг вместо `udiv` на степень двойки | 0 | 0 |
| итого законно | 1 | 1 |

Один процент линейных — 20,8 такта. Законный запас 1/2075.

`fp=True` (реассоциация `FADD`, по умолчанию не делается): 98 тактов на линейных, то есть 97 сверх законного одного. Это другое округление, в панель не попадает.

## В. Базисы

Метка — «движок оставил переписанный граф». Правило синтаксическое, планировщик не зовёт. Совпало с движком на 238 из 238. Логрегрессия: признаки блока, разбиение по файлам, последние 30% после `Random(сид)`, сиды 0, 1, 2.

| Сид | Тест, блоков | Из них метка «да» | Правило | Логрегрессия | Всегда «нет» |
|---:|---:|---:|---:|---:|---:|
| 0 | 48 | 0 | 48 | 48 | 48 |
| 1 | 106 | 1 | 106 | 105 | 105 |
| 2 | 89 | 0 | 89 | 87 | 89 |

На сиде 1 единственный положительный блок попал в тест, в обучении остался один класс, логрегрессия сказала «нет». На сиде 2 она хуже постоянного «нет» (87 против 89). Правило не ошиблось ни разу.

## Г. NNL

Не училось. Правило не промахнулось, условие «оба базиса промахнулись» ложно. Паспорт и веса не создавались.

## Д. Панель

В НЕЙРОСЕТЯХ одна строка: `форма: не трогать` либо `форма: <приём>, −N т. (правило, проверено)`. На `seqreduce` это «дерево ADD, −3 т.». Расписание само не подменяется.

Вывод. На коде `lcc` переписывать почти нечего: компилятор уже развернул целые свёртки, а длинные цепочки — это `FADD`, их без разрешения округления двигать нельзя. Сеть здесь не нужна, точное правило и проверка жадным закрывают вопрос. Оставляем движок и строку панели. Ядро выкидываем, не начиная.
